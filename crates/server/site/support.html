Common questions

A recipe link won't import. Hestia reads the recipe data that most sites publish for search engines. Some sites don't include it. You can still add the recipe by hand with + New.

How do I sync between my iPhone and Mac? Sign in to iCloud with the same Apple ID on both devices. Hestia syncs through your own iCloud account.

Does Hestia collect data? Only if you opt in. See the privacy policy.
